# Klimovich Планер

Автономный рабочий планировщик для Android в стиле Klimovich Marketing.

## Первая версия

- локальные задачи и статусы;
- приоритеты;
- календарь;
- проекты;
- карточка задачи с описанием, сроком, проектом и приоритетом;
- подзадачи, комментарии и вложения из памяти телефона;
- локальные системные уведомления за час или за день до срока;
- подготовленное поле состояния для будущей облачной синхронизации.

Данные хранятся в локальной Room-базе `klimovich_planner.db`. Интернет для работы приложения не требуется.

## Сборка

Требуется JDK 17 и Android SDK 35. Откройте проект в Android Studio и выполните
`Build > Build APK(s)`.

Также в проект добавлен сценарий GitHub Actions. После загрузки проекта в
репозиторий APK автоматически собирается и появляется в разделе Actions → Artifacts.
